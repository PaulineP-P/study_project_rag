# Vision: техническое видение MVP

## Технологии

| Слой | Решение |
|------|---------|
| Язык | Python 3.11+ |
| Управление зависимостями | `uv` |
| Эмбеддинги | `sentence-transformers` (модель `intfloat/multilingual-e5-small`) |
| Векторное хранилище | `chromadb` (локально, без сервера) |
| LLM для генерации | OpenRouter API (`google/gemini-3.1-flash-lite-preview`) |
| UI | `streamlit` |
| Тесты | `pytest` |

Выбор `multilingual-e5-small` обусловлен поддержкой русского языка и
возможностью работать локально без GPU.

## Как строится индекс

1. Скрипт `scripts/build_index.py` читает все `.txt` файлы из папки `data/`
2. Каждый файл разбивается на чанки по границам страниц (`===== СТРАНИЦА N =====`)
   с дополнительным перекрытием 100 символов
3. К каждому чанку добавляются метаданные: имя файла (регион), номер страницы
4. Чанки векторизуются моделью эмбеддингов и сохраняются в ChromaDB
5. Индекс сохраняется локально в папке `index/`

## Как работает поиск

1. Пользователь вводит вопрос в Streamlit-интерфейсе
2. Вопрос векторизуется той же моделью эмбеддингов
3. ChromaDB возвращает top-3 наиболее близких чанка
4. Чанки + вопрос передаются в Gemini с system-промптом:
   отвечать только по предоставленному контексту, указывать источник,
   при отсутствии ответа явно сообщать об этом
5. Ответ отображается в интерфейсе вместе со ссылками на источники

## Что не входит в MVP

- Переранжирование (reranking) результатов поиска
- Семантический чанкинг (используется разбивка по страницам)
- Аутентификация и разграничение доступа
- Кэширование запросов
- Обновление индекса без полной перестройки
- Поддержка форматов кроме `.txt`
- Развёртывание в облаке

## Как запускать проект

```bash
# 1. Установить зависимости
uv sync

# 2. Положить .txt файлы в папку data/
cp /path/to/your/files/*.txt data/

# 3. Построить индекс
uv run python scripts/build_index.py

# 4. Запустить интерфейс
uv run streamlit run app/main.py
```

Переменные окружения (файл `.env`):
```
OPENROUTER_API_KEY=your_key_here
```

Получить ключ: https://openrouter.ai/keys (регистрация бесплатная)

## Границы MVP

- Система отвечает **только** на основе загруженных документов
- При отсутствии релевантного контекста система **явно отказывает**,
  а не генерирует ответ из общих знаний модели
- Индекс строится один раз локально; инкрементальное обновление не поддерживается
