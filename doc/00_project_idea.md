# Project Idea: RAG-ассистент по стратегиям цифровой трансформации регионов РФ

## Проблема

Региональные органы исполнительной власти, разработчики ГИС и аналитики
вынуждены вручную изучать десятки стратегий цифровой трансформации субъектов
РФ, чтобы найти ответы на конкретные вопросы: какие проекты реализуются в
регионе, какие проблемы выявлены в отрасли, какие федеральные решения
рекомендованы к внедрению. Документы объёмные, написаны сложным
бюрократическим языком, а поиск по ключевым словам не учитывает смысловой
контекст запроса.

## Цель проекта

Создать RAG-систему, которая позволяет задавать вопросы на естественном языке
по корпусу стратегий цифровой трансформации регионов РФ и получать точные
ответы с указанием источника (регион, раздел документа).

## Для кого проект

- **Госслужащие и аналитики** — быстрый поиск лучших практик и решений других
  регионов
- **Разработчики ГИС** — поиск требований и рекомендаций по конкретным системам
  (СМЭВ, ЕГИСЗ, ГИС ЖКХ и др.)
- **Исследователи и студенты** — изучение региональной политики цифровизации

## Какие данные используются

- **Источник:** стратегии цифровой трансформации отраслей экономики, социальной
  сферы и государственного управления субъектов РФ (официальные документы,
  прошедшие OCR)
- **Формат:** 87 текстовых файлов `.txt`, структурированных по страницам
- **Масштаб:** 87 региональных НПА; после чанкинга ожидается 1000+ фрагментов
- **Тематика:** цифровизация образования, здравоохранения, транспорта,
  госуправления, ЖКХ, АПК, промышленности, экологии

## Критерий успеха

1. Система корректно отвечает на не менее 3 фактических вопросов по документам,
   указывая источник (регион и раздел)
2. Система корректно отказывает на вопрос, ответа на который нет в базе, вместо
   того чтобы галлюцинировать
3. Все тесты `pytest` проходят (green)
4. Интерфейс Streamlit запускается и доступен локально
