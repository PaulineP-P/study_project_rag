# Описание данных

## Источник

Стратегии цифровой трансформации отраслей экономики, социальной сферы и
государственного управления субъектов Российской Федерации — официальные
документы региональных органов исполнительной власти, прошедшие OCR-обработку.

## Что индексируется

- **Формат:** текстовые файлы `.txt` (результат OCR из PDF)
- **Количество документов:** 88 региональных НПА
- **Регионы:** субъекты РФ от Алтайского края до Ямало-Ненецкого АО
- **Тематика:** цифровизация здравоохранения, образования, госуправления,
  транспорта, ЖКХ, АПК, промышленности, экологии

## Структура документа

Каждый файл содержит маркеры страниц в формате:
```
===== СТРАНИЦА N =====
текст страницы...
```

## Параметры индексирования

| Параметр | Значение |
|----------|----------|
| Метод чанкинга | По маркерам страниц |
| Размер чанка | до 2000 символов |
| Перекрытие | 100 символов |
| Итого чанков | 16 686 |
| Метод индексирования | TF-IDF (scikit-learn) |
| Размер матрицы | 16 686 × 50 000 |
| Метрика поиска | Cosine similarity |
