## Итерация 0 — Структура репозитория и окружение

**Задачи:**
- [ ] Создать репозиторий на GitHub
- [ ] Инициализировать проект через `uv init`
- [ ] Создать структуру папок: `data/`, `index/`, `scripts/`, `app/`, `rag/`, `tests/`, `doc/`
- [ ] Добавить `.gitignore` (data/, index/, .env, __pycache__)
- [ ] Создать `.env.example` с заглушкой `OPENROUTER_API_KEY=your_key_here`
- [ ] Положить все документы в `data/`
- [ ] Скоммитить документацию: `doc/00_project_idea.md`, `doc/vision.md`, `doc/conventions.md`, `doc/tasklist.md`

**Проверка:**
```bash

ls data/*.txt    # файлы на месте
```

